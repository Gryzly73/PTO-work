# Symbols baselines

These JSON files are development-only S3-S6 profiles. Timing is recorded for
fresh runs but excluded from the reproducibility digest. Customer PDFs and
their content remain outside version control. The page 35 expected GT records
the manually verified compact right-column legend: 19 general rows and seven
engineering-network rows. Its two headings are not legend entries.

Snapshots made from legacy sidecars use `clusteringBackend: "unknown"` because
the backend was not recorded by those runs.
