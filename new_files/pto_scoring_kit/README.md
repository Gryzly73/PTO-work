# pto_scoring_kit — исторический чек-лист-скоринг

Набор от июня 2026, когда качество мерили по рукописным чек-листам: для
каждой из шести «трудных» страниц был список того, что на ней обязано быть
(марки, отметки, диаметры), и скрипт считал, сколько пунктов нашлось.

**Это третья, самая старая из трёх метрик проекта** (см. `README.md`, раздел
«Метрики — их три, не смешивать»). Её потолок — около 64 %, и с нынешними
цифрами полноты она **не сравнивается**: другая шкала, другой набор страниц.
Сейчас качество меряется без модели — `bench_text_layer.py` и
`bench_dwg_text.py`.

## Что здесь осталось

| Файл | Что это |
|---|---|
| `score_real_testset.py` | сам скоринг: матчеры `contains` / `any_contains` / `all_contain` |
| `ground_truth/` | чек-листы к страницам |
| `order.json` | соответствие «номер страницы → фикстура» |
| `out_ocr_live.md`, `synth_typeaware.md` | два прогона июня, на которых он запускался |

Всё остальное, что описывал прежний README (`pages/`,
`build_testset_pdf.py`, `run_baseline.sh`, собранный `real_testset.pdf`,
журналы цикла), в репозиторий не входило и локально не сохранилось. Поэтому
команды из того README не выполнятся — кит оставлен как история метрики, а не
как рабочий инструмент.

Сам тест-сет из шести страниц жив и лежит отдельно:
`new_files/real_testset.pdf` плюс эталоны в
`ЭТАЛОН — оригинал PDF + идеальный Markdown/`; по ним работает
`compare_to_etalon.py`.
