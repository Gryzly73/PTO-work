## 1. Вердикт

Получился **инвентарь**, не описание чертежа по критерию плана.

Можно без картинки сказать: какие кружки ИГЭ (подпись грунта из каталога КР1) лежат на каком именованном виде.

Нельзя без картинки ответить: «под осью N на разрезе XII–XII — ИГЭ-2».

Причина не в том, что конвейер «не дочитал» ось. В DWG КР1 **нет линии оси через разрез** — только марки сетки над видом (`INSERT` на слое `OSI`, подпись «Ж / 7», стебель ~6 мм). Стык по ближайшему x отвергнут: зазоры до второй оси бывают 0.07–0.3 мм, кружки стоят столбиками скважин, не под каждой осью.

## 4. Ограничения (не чинить тем же циклом)

### 4.1. Ось

В sidecar нет связи `instanceId → axisId`.  
В DWG нет геометрии колонки: 60 марок осей (1–15 × 4 вида) на y ≈ 24.7; в `field_geometry` линии оси нет (`kind: line` = 0). Стебель блока короче порога 8 мм. Agent «положить линию оси» не открывать. Стык по x не делать.

На ИГР `axisIds` пустые, `textLabelAxis` = 0. Эталона стыка на КР1 нет — ИГР с осями не начинать.

### 4.2. Штрих слоя

160 hatch. На КР1 34 SOLID ошибочно повешены на строку УГВ; 126 без подписи. На ИГР `fieldGeometryLabeled` = 0. Отдельный опасный цикл, не сейчас.

### 4.3. Скважины, пробы, границы на поле

В легенде КР1 строки есть. На поле без уникального `blockdef` — `unresolved` (на ИГР кластеры CPE/CCE/CME/CGE, PR_*). В индекс проекта не входят: почвенный слой, песок средней крупности, отметки, три линии границ.

### 4.4. Словарь, который не чинили

- заголовок «Г Р А Н И Ц Ы» всё ещё строка легенды (не знак);
- УГВ склеено с «дата замера» (`LE-4b32466babfb639c`).

В ключ заголовок не класть. Склейку УГВ — отдельный чат, если понадобится.

### 4.5. Вне этих двух листов

Нет DWG ПБ/ОДИ. ПЗУ без `_Ссылки` — генплан из нашего DWG не собрать ([`ОГРАНИЧЕНИЯ_XREF.md`](ОГРАНИЧЕНИЯ_XREF.md)). Таблицы ФМХ и штамп как отчёт — другая задача. ГОСТ «с памяти» не подставляли. Сводка препятствий и вывод — [`ПРЕПЯТСТВИЯ_РАСПОЗНАВАНИЯ_ГОСТ.md`](ПРЕПЯТСТВИЯ_РАСПОЗНАВАНИЯ_ГОСТ.md).

Проза «Т-образные фундаменты, розовая штриховка» — только модель по картинке, вне этого снимка. Печать **этого** DWG в PDF ось через разрез не создаст.

## 5. Что можно честно писать в узком отчёте

На каждый закрытый лист — четыре блока, без выдумки оси:

1. **Паспорт** — одна строка (какой DWG, какой лист).
2. **Ключ** — каталог КР1 без строки «ГРАНИЦЫ» как знака.
3. **Содержание** — только `confirmed`: вид → список грунтов (и счёт кружков). Не «под осью N».
4. **Пропуски** — ось как марка сетки, не колонка; штрих не подписан; скважины/пробы на поле без `blockdef`; один кружок-образец легенды на КР1.

Пользовательский текст — только `confirmed`. `probable` в отчёт не входит.

## 6. Что не делать следующим шагом

- не сессия 2b, не сборщик отчёта «как будто критерий закрыт»;
- не Agent на линию оси и не стык по x;
- не смешивать КР1 с ТХ/ПЗУ в одном срезе;
- не брать `review_ideal_igr` вместо `review_ideal_igr_kr3`.

Дальше — только новый вопрос цикла (штрих, скважина на поле, остальные ИГР) или запрос составителю: считают ли слой «под осью N» по марке сверху / по скважине. Пока ответа нет, этого поля в отчёте нет.
