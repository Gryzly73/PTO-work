## 1. Принципы harness

1. **Один чат = один цикл = один вопрос = один срез.** Не «реализуй план», не этапы A–F пачкой, не КР+ТХ+ПЗУ в одном `selection.json`.
2. **Ask → Agent → Ask.** Ask ничего не меняет. Agent — одна дыра. Приёмка — **новый** чат Ask по sidecar до/после, не тот же тред.
3. **Новый чат**, если сменился вопрос, срез или режим «смотрим / правим».
4. **Fail-closed.** Нет однозначной улики — пропуск. Ложная подпись хуже дыры. `probable` в ведомость не поднимать. `expected` в манифесте не заполнять.
5. **Один факт — один источник.** Легенду КР1 не перечитывать. ИГР берут `project_legend_catalog`. ИДЕАЛ — сверка смысла, не GT.
6. **Цикл закрыт только по артефактам**, не фразой «код поправили». Смотреть `review.json`, `legend_entries.json`, `field_geometry.json`, не картинку листа целиком.
7. **Регрессия кружков.** После любого патча легенды или резолвера: КР1 `confirmed` = **70**, улика `exact_block_definition`; ИГР КР3 = **159**, улика `project_exact_block_definition`. Поплыли — откат.
8. **Не в этих чатах:** таблицы ФМХ, VLM-проза / PASS-A на лист, классификатор ГОСТ, печать DWG→PDF, ось по ближайшему x, коммит DWG и `local_runs/`.

Модель Agent: Grok 4.6 high fast. Узкий патч с жёстким «не трогать» — можно GPT Soul. Gemini — обзор, не правка sidecar.

`local_runs/` в gitignore: `@` часто не видит. Файлы **перетаскивать** в чат. Строки вида `@ путь` из карточки в промпт не копировать.

## 4. Как запускать промпт

Текст в блоке **Промпт** — готовый запрос, не шпаргалка. Хвост «не трогать» уже внутри блока, отдельно не дописывать.

1. **Новый чат** (не продолжать предыдущую сессию).
2. Режим: **Ask** или **Agent** — как в карточке. Ask код не меняет.
3. Модель Agent: Grok 4.6 high fast. Ask — любая из рабочих. Gemini — обзор, не правка sidecar.
4. Файлы из карточки **перетащить**. Строки `@ путь` в чат не копировать. `local_runs/` в gitignore: `@` часто не видит.
5. Вставить блок «Промпт» целиком, отправить.

Приёмка — **ещё один** чат Ask, не тот же тред. Следующий цикл не открывать, пока текущий не закрыт по sidecar.

База КР1 (подставлять в «перетащить», где написано «срез КР1»):

- `local_runs/review_ideal_kr1/selection.json`
- `local_runs/review_ideal_kr1/kr1-geology-p1/review.json`
- `local_runs/review_ideal_kr1/kr1-geology-p1/dwg_symbols/page_0001/legend_entries.json`
- `local_runs/review_ideal_kr1/kr1-geology-p1/dwg_symbols/page_0001/field_geometry.json`
- `local_runs/review_ideal_kr1/kr1-geology-p1/CROP_DECODE.md`
