## Зачем вообще P01

До витка в репозитории уже были `deglyph.py` и `pdf_tables.py` по ТЗ, но **живой контур их не вызывал**:

- HTTP (`service/convert.py`) отдавал сырой слой: битый ToUnicode → пустой `extractedText`, таблиц в клиентском листе нет.
- `--layer-aware` смотрел на сырой `get_text`. На комплекте вроде `01.pdf` (`text_len: 0`) и на чинимом ToUnicode тайлы (PASS-B) всё равно шли — дорого и с выдуманными цифрами.
- Паспорт на большом листе без CAD-меток всегда ставил `scheme` (`large drawing default→scheme`). Ведомость резалась как чертёж.
- PASS-T («перенеси таблицу целиком») включался только вручную: `--table-pages`. HTTP этого флага не имел.

P01 закрыл проводку слоя/таблиц/паспорта/роутинга. Легенду, карман фактов, ИГЭ↔ПГ и выравнивание CLI-дефолтов сознательно не трогали.

## 1. Сделанные доработки

Что изменилось в коде и **какой эффект ожидался**. Где эффект частичный — сказано прямо.

### D0 — harness

Появились `docs/active/`, очередь D0–D6, правило «один виток = одна фаза». Код конвейера не менялся.

**Должно дать:** не смешать P0 (слой) с промптами легенды и сменой дефолтов.

### D1 — pytest-замок

Каталог `tests/`, `pytest.ini`, якоря на *тогдашнее* поведение: шапка `**Файл:**`, garbled → пустой слой, deglyph без двух свидетелей, пустой большой лист → `scheme`.

**Должно дать:** отличить «так и было» от регрессии следующих фаз. Без этого D5 нельзя было честно менять паспорт.

### D2 — `doc_context.py`

Один pre-pass на весь PDF без VLM: глиф-map (гейты 90/85), рамки штампа, шифр комплекта. Кэш `doc_context.json` (mtime + size). В выдачу ещё не вшит.

**Должно дать:** словарь глифов и шифр считаются один раз на документ, не на каждый лист и не внутри воркера.

### D3 — слой и таблицы в клиентский лист

Воркер до пула листов делает `ensure` → `run_dir/doc_context.json`. `convert` принимает `ctx`: decode → normalize → garbled/пусто → `""`. Читаемый слой + сетка → блок `## Таблицы листа`. Если слоя нет, а шифра нет в PASS-A — дописывается `source_note`. `PAGE_SCHEMA` 2 → 3.

**Должно дать:** на комплекте с чинимым ToUnicode (ориентир — ИОС2) в API непустой `extractedText` и таблицы по геометрии, не вычитанные моделью. Сырой `page_NNNN.md` (PASS-0/A/B) не ломается. На немом `01.pdf` слой по-прежнему пустой — это честно.

### D4 — layer-aware смотрит починенный слой

`run_vlm` читает тот же `page_layer` + кэш. PASS-B пропускается, если после decode/normalize длина ≥ 400. `find_tables` в эту проверку не ходит.

**Должно дать:** на живом/починенном слое один запрос модели (PASS-A), без нарезки на тайлы. Экономия токенов и меньше выдуманных цифр. Короткий штамп (<400) тайлы не отменяет. Повтор одинаковых CAD-меток после `normalize` схлопывается — такой слой тоже не считается «живым текстом».

### D5 — паспорт: сетка, не «большой → схема»

Перед дефолтом `scheme`: плотная H/V решётка из `get_drawings()` (h≥8, v≥4) → `kind==table`. Ветка `plan` (`is_wide` / метки) не перебивается. Пустой лист без линий остаётся `scheme`.

**Должно дать:** векторная ведомость больше не уходит в «схему» и четверти плана.

**Факт пробы:** `01.pdf` (листы 1–5) — **полностраничный растр**, `drawings=0`, `find_tables=0`. КР5 стр. 5 честно остаётся `scheme`. North star «этот файл → table» этим комплектом не закрыт.

### D6 — авто-PASS-T

Предикат `should_run_pass_t`:

```text
want = --table-pages  или  (sheet_aware и kind==table и слой < 400 символов)
```

Тело PASS-T (промпты, три попытки) не менялось. HTTP нового env не получил: при `PTO_SHEET_AWARE=1` авто достаточно.

**Должно дать:** векторная таблица без слоя сама идёт в «перенеси целиком», не режется тайлами. Живой слой модель не перепечатывает (таблицы уже из D3). Растровый КР5 по-прежнему только с `--table-pages 5`.
