Дата: 31.08.2026.  
Задача: условные обозначения на чертеже, не штамп как отчёт и не таблицы ФМХ.  
Содержание плана: [`ПЛАН_ОПИСАНИЕ_ЧЕРТЕЖА_DWG.md`](ПЛАН_ОПИСАНИЕ_ЧЕРТЕЖА_DWG.md) §4–5.  
Снимок геологии: [`СОСТОЯНИЕ_РАСПОЗНАВАНИЯ_ЧЕРТЕЖА_DWG.md`](СОСТОЯНИЕ_РАСПОЗНАВАНИЯ_ЧЕРТЕЖА_DWG.md), кратко: [`СОСТОЯНИЕ_РАСПОЗНАВАНИЯ_ЧЕРТЕЖА_КРАТКО.md`](СОСТОЯНИЕ_РАСПОЗНАВАНИЯ_ЧЕРТЕЖА_КРАТКО.md).

## Вывод

**Распознавать значки «по ГОСТ» как основной путь сейчас нельзя и не нужно.**  
Нет эталонной библиотеки паттернов, нет ответа составителя, каким альбомом бюро реально пользуется, на части листов нет самой геометрии или самого DWG. Кандидата ГОСТ до `confirmed` не поднимаем. `expected` в манифесте не заполняем выдумкой.

**Смысл анализа есть — но не ГОСТ-классификатора.** Имеет смысл продолжать то, что уже работает: легенда листа / каталог раздела и уникальный `blockdef`. На КР1 геологии это 70 `confirmed` кружков грунта; на ИГР КР3 — 159 по тому же каталогу. Это проектный словарь (ИГЭ-2), не код 21.302.

Имеет смысл узко чинить словарь и привязку на одном срезе (скважины без `blockdef`, штрих, склейки легенды) — **без** подстановки имени грунта из ГОСТ.

Не имеет смысла сейчас:

- цикл «распознать лист по 21.302 / 21.201 / 21.204 / 21.205»;
- ГОСТ по PDF пожарки (уже 0 `confirmed`);
- 21.204 на ПЗУ без `_Ссылки`;
- общий каталог ГОСТ на 94 DWG;
- классификатор «модель знает норматив».

Штамп 21.101, форматы 2.301, шрифт 2.304 — это оформление листа, не знаки. Их не трогаем и не считаем прогрессом по условным обозначениям.

## Правило статуса

Конвейер не классифицирует знаки с памяти модели.

| Ситуация | Статус |
|---|---|
| Подпись с листа совпала с геометрией (легенда / `blockdef`) | `confirmed`, ГОСТ не нужен |
| Геометрия совпала с **одним** паттерном ГОСТ, подписи нет, тип листа известен | максимум `probable`, в пользовательский отчёт не идёт |
| Два паттерна ГОСТ или конфликт с легендой листа | пропуск |
| Номер ГОСТ не написан у знака в DWG | в отчёт номер не ставим |

ИГЭ-2 — номер комплекта, не код 21.302. Подменять кружок именем грунта из таблицы ГОСТ нельзя.

## Препятствия

### 1. Нет библиотеки эталонных паттернов

Чтобы сказать «этот штрих = суглинок по 21.302», нужна закрытая таблица: паттерн → один код. Её нет. Без составителя или ручной разметки этап 21.302 — после стабильного каталога КР1, не вместо него. Неоднозначный паттерн (в эталоне два состояния грунта = «пустой прямоугольник») в `confirmed` не кладём.

### 2. Нет ответа, каким ГОСТ пользуются на объекте

Книжный 21.302 и штрих бюро могут совпасть внешне и значить разное. Пока составитель не сказал «как в книге» или «наш альбом», кандидат остаётся `probable` или пропуск. Это блокирует превращение ГОСТ-кандидатов в `confirmed`, не блокирует легенду КР1.

### 3. Мастер легенды по разделу — иначе эвристика «самый полный лист»

Знак на поле стыкуется со словарём раздела, не с глобальным ГОСТ.

Три уровня: лист → раздел → комплект. Комплект не строим (КР ≠ ТХ ≠ ПОС).

**Мастер** — файл, который составитель назвал полным словарём темы. Тогда ИГР только читают поле.

Ответа нет. Эвристика: в папке раздела взять лист с наибольшим числом строк «Условные обозначения». Для геологии КР это КР1 лист 1 (26 строк) — совпало. Если самый длинный блок окажется не тем, ошибка разъедется по всем ИГР. Конфликт «① = разные тексты» не затираем.

Планы КР и ТХ — свои мастера, не геология. Один «полный лист на 94 DWG» недопустим.

### 4. На поле нет той геометрии, которую описывает норматив

На КР1 нет линии оси через разрез — только марки сетки. Критерий плана «под осью 7 на XII–XII — ИГЭ-2» из sidecar не собирается. Это не «не дочитали ГОСТ».

Скважины `CPE`/`CCE`/`PR_*`, штрих грунта, границы: в легенде строка есть, на поле нет уникального `blockdef` → `unresolved`. 21.302 как раз про них, но без однозначного паттерна статус не поднимаем. SOLID на КР1 ложно клеился к УГВ.

### 5. Слой и имя блока не равны ГОСТ

`SVARKA` (сотни unknown на комплекте) — не шов 2.312. Сварка только если `signature` есть в `gost_welds.json` с кодом.  
Слой `!!!В1` сильнее имени «водопровод» из 21.205: марка проектная.  
`*U` / `Layer1` / взорванная геометрия без CAD-стандарта — декор и знак неразличимы.

### 6. Пакет `_Ссылки` — ГОСТ 21.204 на ПЗУ без XREF не начать

XREF — чужой DWG, содержимое в присланном файле не лежит. ПЗУ «Жуковский»: в файле рамка и штамп, генплан в папке `_Ссылки`. Папки нет. На контрольном листе почти только штамп.

**21.204** — границы, озеленение, транспорт генплана. Без геометрии плана классифицировать нечего. Печать этого DWG даёт ту же пустую рамку. Нужны `_Ссылки`, либо PDF, который печатали уже с решёнными ссылками. Легенду ПЗУ на весь комплект не собираем, пока ссылок нет.

### 7. DWG ПБ / ОДИ / АР — 21.205 по пожарке и ОДИ не из чего читать

В `new_files/dwg` нет разделов ПБ и ОДИ. АР как альбом тоже не прислан (куски АР бывают как XREF внутри КР — это не пожарка). Эталоны `ИДЕАЛ_19` / `ИДЕАЛ_21` с вектором не сверить.

**21.205** по санитарно-техническим и пожарным схемам пробовали обходом: PDF `01.pdf`. 25.08.2026: 37 строк легенды, 606 кандидатов, **`confirmed` 0**, `probable` 546. Картинка без независимой улики статус не поднимает. Повторять этот анализ незачем, пока нет DWG или явного «будут только PDF».

### 8. Техника конвертера и один словарь на всё

`dwg2dxf` недетерминирован: анонимные `*U` плывут — на них ГОСТ не вешать.  
Один каталог ГОСТ/легенды на 94 файла даст ложные `confirmed`.  
VLM-проза и PDF-матчер в этот контур не входят.

### 9. Нет CAD-стандарта от составителя

Какие слои официальные, какие блоки = знак легенды, какие взорваны, что значит цвет/CTB — неизвестно. Без этого «похоже на 21.201» неотличимо от узла или выноски.

## Есть ли смысл что-то анализировать сейчас

| Делать | Не делать |
|---|---|
| Легенда КР1 и привязка кружков на поле / ИГР | Цикл «внедрить ГОСТ 21.302» |
| Узкие дыры sidecar: скважина без `blockdef`, штрих, склейка УГВ | Повтор PDF `01.pdf` / 21.205 |
| Честный отчёт: паспорт, ключ легенды, только `confirmed`, пропуски | «Под осью N» и имя грунта из ГОСТ |
| Инвентарь unknown/объектов как очередь, не как ГОСТ | 21.204 на ПЗУ без `_Ссылки` |
| Письмо составителю (отдельный Ask) | Один каталог на весь комплект |

**Итог одной фразой:** значки по ГОСТ сейчас распознать нельзя в том смысле, в каком это «соответствие альбому»; анализировать **есть смысл** продолжение легенды и поля, **нет смысла** открывать ГОСТ-классификатор до библиотеки паттернов и ответа составителя.
