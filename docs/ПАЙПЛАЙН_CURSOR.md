Как вести задачу **анализа чертежа** по DWG в Cursor: один чат — один цикл Harness.

Содержание задачи и ограничения — в [`ПЛАН_ОПИСАНИЕ_ЧЕРТЕЖА_DWG.md`](ПЛАН_ОПИСАНИЕ_ЧЕРТЕЖА_DWG.md).  
XREF — в [`ОГРАНИЧЕНИЯ_XREF.md`](ОГРАНИЧЕНИЯ_XREF.md).  
Этот файл — только порядок работы в редакторе, не повтор плана.  
Готовые тексты запросов и режимы Cursor — **§5–6**.

---

## 1. Что делаем в этих чатах

Только графическое содержание листа: знаки, легенда, привязка к полю (вид, ось).

Текст и таблицы — **только если без них знак не читается** (расшифровка легенды, номер ИГЭ в кружке, заголовок вида, отметка на разрезе, таблица штриха грунта).

Не делаем в этих чатах: таблицы ФМХ, штамп как отчёт, PASS-B, VLM-прозу, классификатор ГОСТ «с памяти», печать DWG→PDF.

Готовая легенда раздела уже есть — не извлекать заново:

`local_runs/review_ideal_kr1/kr1-geology-p1/dwg_symbols/page_0001/legend_entries.json`

Источник — DWG КР1 «Геологические разрезы», лист 1. На ИГР её уже подтягивают как `project_legend_catalog`. Эталон `ИДЕАЛ_*.md` — сверка **смысла**, не источник словаря.

## 2. Правило чата

**Один чат = один цикл = один вопрос по одному срезу.**

Не открывать Agent с «реализуй план» или «сделай этапы A–F». Не класть в один `selection.json` геологию вместе с ТХ / планами КР / ПЗУ.

| Режим | Когда | Что можно менять |
|---|---|---|
| **Ask** | разобрать артефакты, список дефектов, приёмка sidecar | ничего |
| **Agent** | одна правка (один дефект словаря **или** одна дыра привязки) | код цикла + тот же срез `local_runs/` |
| **Ask** снова | приёмка: каталог не поплыл, вопрос цикла закрыт | ничего |

Модель для правок кода: Grok 4.6 high fast. Узкий точечный патч с жёсткими «не трогать» — можно GPT Soul. Gemini — обзор, не правка sidecar.

Новый чат, если сменился вопрос цикла, срез или режим «сначала смотрим / теперь правим».

---

## 3. Что прикладывать в чат

Минимум, не весь репозиторий и не весь `local_runs/`:

1. этот файл + нужный § из плана (`§7` этап A / B / …);
2. `local_runs/<срез>/selection.json` — какие `id` и зачем (`selectionReason`);
3. два-три артефакта среза: `legend_entries.json`, `review.json` (шапка: `confirmed` / `probable` / `anomalyCodes` / `bindingEvidence`), при необходимости `REPORT.md`;
4. кропы того же листа (`legend_crops/`, `page_review.svg`), если вопрос про склейку знака. `ИДЕАЛ_*.md` не прикладывать как GT.

В промпте всегда:

- вопрос цикла одной фразой;
- «не трогать таблицы, VLM, ГОСТ, ПЗУ, ТХ; не заполнять `expected` в манифесте»;
- «легенду КР1 не перечитывать, использовать готовый JSON».

## 5. Как запускать промпт в Cursor

Текст сессии из §6 — **готовый запрос**, не шпаргалка. Абзац «вопрос цикла» из старых заметок в чат не копировать.

1. **Новый чат** (не продолжать предыдущую сессию).
2. В поле чата выбрать режим: **Ask** или **Agent** — как в карточке сессии. Ask код не меняет; Agent имеет право править.
3. Модель: для Agent — Grok 4.6 high fast; для узкого патча с жёсткими «не трогать» можно GPT Soul. Ask — любая из этих. Gemini — только обзор, не правка.
4. Приложить файлы из карточки. Строки вида `@ путь` из этого документа **не копировать в чат** — это список, не команда. Документы в `docs/` находятся через `@`. Файлы в `local_runs/` и `*.json` в `.gitignore`: `@` их часто не видит. Откройте файл в проводнике и **перетащите в чат** или вставьте полный путь через Add Context.
5. Вставить блок «Промпт» целиком, отправить. Список `@` перед промптом не вставлять.

Приёмка после Agent — **ещё один новый чат в Ask**, не тот же тред. Следующую сессию не открывать, пока текущий вопрос не закрыт по sidecar.

| Сессия | Режим Cursor | Модель | Когда открывать |
|---|---|---|---|
| 0 | **Ask** | любая из рабочих | сейчас, без кода |
| 1 | **Agent**, затем Ask на приёмку | Grok 4.6 high fast | сразу после 0: **только границы**, не все пункты списка |
| 2a | **Ask** | любая из рабочих | после закрытой 1 (или если словарь уже ок) |
| 2b | **Agent**, отдельный чат | Grok 4.6 high fast | только если 2a: привязки не на поле |
| 3 | **Agent** (сначала можно Ask «почему 0») | Grok 4.6 high fast | только после устойчивого B на КР1 |
| 4 | **Ask**, код отчёта — отдельный Agent | Ask / Grok | когда sidecar сессий 2–3 достаточны |

## 7. Как принимать цикл

Цикл закрыт, если на вопрос в `selectionReason` есть ответ **по артефактам**, без картинки листа целиком:

- Ask: список находок / дефектов записан;
- Agent: повтор того же среза, каталог не разъехался, статус `confirmed` не хуже без объяснения;
- в пользовательское описание по-прежнему только `confirmed`; `probable` — очередь review.

Не закрывать цикл фразой «код поправили». Закрывать сравнением sidecar до/после.

---

## 8. Чего не делать в Cursor на этой задаче

- Не прикладывать весь `local_runs/` и не просить переписать конвейер.
- Не сверять слово в слово с `ИДЕАЛ` (OCR, петли, таблица 7.2.1).
- Не заполнять `expected` в `MANIFEST.local.json`.
- Не поднимать ГОСТ-кандидата до `confirmed`.
- Не коммитить DWG, кропы, JSON прогонов.
- Не продолжать чат, если вопрос уже другой: открыть новый и приложить новый срез.
