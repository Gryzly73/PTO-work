# Этот этап — для клиента

01.09.2026.  
Геологические чертежи КР1 и ИГР. Сверка с ТЗ — не этот этап.

Сейчас по кружкам грунта на разрезе уже можно опереться на отчёт. Дальше закрываем дыры на тех же листах: ложные и недостающие подписи, шум в легенде, те же ИГР на КР2 и КР4.

---

## Какие проблемы решаем

| Сейчас | После доработки |
|---|---|
| Часть заливок слоёв подписана как уровень грунтовых вод | Ложную подпись снимаем. Без имени лучше, чем «УГВ» на грунте |
| В легенде заголовок «границы» выглядит как знак; отметка воды склеена с датой замера | Заголовок не знак. Вода и дата — разные строки |
| Служебные блоки CAD (подписи, служебные данные) числятся нераспознанными знаками | Убираем из очереди знаков: это не грунт и не скважина |
| Скважины и пробы на поле видны, в легенде строки есть, подписи нет | Подписываем тип (скважина / образец / проба), только если соответствие однозначное. Номер скважины не выдумываем |
| Штриховка слоя почти без имени грунта | Подписываем, только если образец в легенде уникален. Имя с кружка рядом не берём |
| ИГР КР2 и КР4 тем же правилом ещё не прогнаны | Тот же словарь КР1, без повторного чтения легенды |

В отчёт по-прежнему только уверенные совпадения. Сомнение — очередь проверки, не ведомость.

---

## Ограничения

- **«Под осью N — такой-то грунт»** этими работами не появится: на чертеже нет линии оси через разрез, только марки сетки сверху. Как это читает бюро — их ответ, не догадка программы.
- Сверка проекта с ТЗ и список замечаний — не этот этап.
- Генплан ПЗУ из нашего файла не собрать: план во внешних ссылках, папки нет.
- ПБ и ОДИ: DWG в комплекте нет.
- Значки «как в ГОСТ» с памяти не подставляем.
- Целый лист нейросетью не пересказываем. Имена грунтов и числа — из файла.
- Если стык скважины или штриха неоднозначен — в отчёте останется пропуск, не правдоподобная подпись.
