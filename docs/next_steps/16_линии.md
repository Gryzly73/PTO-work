## Правила

| Вход | Kind | Подпись |
|---|---|---|
| LINE/POLYLINE ≥ 8 мм, центр в поле | `line` / `closed` | нет, пока нет уникального `legend-vector-v1` этого листа |
| тот же хеш, ровно одна строка легенды листа | то же | `label` из строки |
| две строки с одним хешем | то же | без подписи (конфликт) |
| центр в штампе / легенде / примечаниях | — | не полевой объект |
| слой `FORMAT` / `NADPISI` | — | пропуск |
| легенда ПЗУ / другого файла | — | не применяем |

INSERT не создаём: `fieldGeometry` — отдельная коллекция, как `textLabels`.

---

## Ограничения

1. **Видимость ≠ расшифровка.** 80 контуров кликаются как геометрия. Подписи 0: образец легенды — кроп ячейки, полевой контур — другой масштаб. Слабый стык «цвет + толщина» не брали.

2. **Бюджет 80, сначала замкнутые.** Открытые стены-отрезки на ТХ-1 в этот потолок почти не попали. Не весь план.

3. **Нативный HATCH не снимаем.** `HatchPolicy.IGNORE`: заливка грунта не приходит типом `hatch`. На геологии видны замкнутые полилинии слоёв `линия 05` / `Skv`.

4. **Не легенда ПЗУ.** Проектный словарь генплана не применяли. Лист без строк легенды остаётся без подписи (тест).

5. **Два листа, не десятка.** `review_10_stamp` / `review_10_context` / `review_10_zones` целы. 82 / 48 не трогали.

6. **`drawing_field` не перерезали.** TEXT осей как в [13](13_текст.md) / [15](15_зоны_листа.md).
