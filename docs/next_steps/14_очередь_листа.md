## Рамка (на все пять шагов)

- Цель клика: разный проверяемый ответ, не ноль unknown.
- Fail-closed: нет якоря / нет стыка / нет образца *этого* листа → ключ или подпись не ставим.
- Конвейер ролей не ломаем. Confirmed / probable **82 / 48**. `review_10_stamp` / `review_10_context` не затираем.
- INSERT в таблице легенды не переклассифицируем «новыми грунтами». Безымянный `*U` и слой `SVARKA` целиком не трогаем.
- Не делаем: OCR/VLM на лист; пересчёт `drawing_field` в v1 (TEXT осей завязан на вычитание штампа, [13](13_текст.md)); Docker 575; охота вилки 2.312 среди типов; HTML-копия десятки ради зон.

## 1. Зоны легенды и примечаний

**Сейчас.** Строки легенды извлекаются (`detect_legend_entries`, заголовок `_HEADING`). Окна штампа, поля, легенды и якоря примечаний — на двух листах ([15](15_зоны_листа.md)). Overlay — пунктир без новой буквы. Тело примечаний не читаем.

**Клик после шага.** Клик в таблицу легенды и клик в поле плана — разные точки. Клик в «Примечания» — зона примечаний, не грунт и не штамп. Не новые грунты и не чтение текста примечаний.

**Не** подписывать INSERT в таблице легенды заново и не перерезать `drawing_field`.

### 1.1. Что появляется в JSON

Опциональные ключи `legend` и `notes` в `sheetZones`. `title_block` по-прежнему обязателен, если объект зон есть.

- `legend`: объединение bbox уже найденных `legend_entries` + заголовок. Нет заголовка / нет строк — ключа нет, INSERT не выдумываем.
- `notes`: заголовок вроде «Примечан…» (отдельный regex, как легенда). Нет якоря — нет зоны. Текст примечаний не «читаем».
- Overlay: второй пунктир, **без новой буквы** (как штамп). Карточка HTML не обязательна.

Прогон: [15](15_зоны_листа.md) — каталог `local_runs/review_10_zones`, геология + ТХ-1. Не десятка, не stamp. Цифры окон и 82 / 48 не трогали.

### Тесты

```
py -3 -m unittest test_dwg_symbols
```

| Тест | Что проверяет |
|---|---|
| заголовок легенды + строки | `sheetZones.legend` есть |
| нет заголовка | ключа `legend` нет |
| якорь «Примечан…» | `sheetZones.notes` есть |
| без якоря примечаний | ключа `notes` нет |
| штамп и поле | `title_block` / `drawing_field` как в [08](08_чтение_штампа.md) |
| overlay | пунктир легенды, нет `>L</text>` / новой буквы |
| грунт / TEXT-ось | confirmed и роль оси не меняются |
| старая десятка | HTML/sidecar без ключей `legend`/`notes` не падают |

### Анализ / ограничения

1. **Это окна, не словарь.** Зона не создаёт новых confirmed грунтов. Совпадение значка с легендой листа уже работает (82 / 48).
2. **Нет якоря — нет зоны.** Заголовок легенды или «Примечан…» обязательны. INSERT таблицы не выдумываем.
3. **`drawing_field` в v1 не перерезаем.** TEXT осей на плане блока 1 завязан на текущее вычитание штампа ([13](13_текст.md)).
4. **Текст примечаний не читаем.** Только рамка зоны.
5. **Не десятка и не stamp.** Каталог `review_10_zones`; `review_10_stamp` / `review_10_context` целы.

### Готово, когда

На геологии есть `sheetZones.legend`; на листе без заголовка ключа нет; при якоре примечаний есть `notes`; overlay без новой буквы; 82 / 48; юнит-тесты из таблицы зелёные. Прогон двух листов: [15](15_зоны_листа.md).

## 2. Линии и штриховки

**Сейчас.** Контур кликается ([16](16_линии.md)). Подпись — только уникальный образец *этого* листа: простой штрих ячейки, нативный HATCH или векторный хеш ([17](17_подпись_контура.md)). На геологии 34 подписи (УГВ `SOLID`); грунты `Fill` и план ТХ-1 без уникального образца — без подписи. Генплан ждёт шаг 5.

**Клик после шага.** «Это линия / штриховка на поле плана». Подпись («грунт …», «покрытие …») — только если совпал образец *этого* листа. Не легенда ПЗУ (шаг 5) и не «стена из ГОСТ».

**Не** переносить словарь генплана и не подписывать контур без образца.

### Тесты

| Тест | Что проверяет |
|---|---|
| линия/штриховка в поле | объект виден, не INSERT |
| совпал образец этого листа | подпись из строки легенды листа |
| тик ячейки / уникальный HATCH | длинная стена и заливка садятся без хеша большого контура |
| образец с другого листа / конфликт | без подписи, не probable с чужого файла |
| 160 замкнутых + подписанная линия | линия в бюджете |
| в зоне легенды | не полевой объект |
| confirmed-грунт INSERT | 82 не сдвинулись |
| ПЗУ без шага 5 | геометрия есть, легенда ПЗУ не применена |

### Анализ / ограничения

1. **Видимость ≠ расшифровка.** Сначала контур, потом подпись.
2. **Только легенда этого листа.** Межфайловый перенос грунтов сюда не тащим.
3. **Генплан ждёт шаг 5.** Конфликты рисунка ([02](02_проектная_легенда_и_конфликты.md)) на этом шаге не разводим.
4. **Не весь TEXT.** Выноски и слой `0` по-прежнему не оси ([13](13_текст.md)).

### Готово, когда

На контрольном плане/разрезе линия или штриховка кликается как геометрия; подпись есть только при стыке с образцом того же листа; ПЗУ не подписан легендой комплекта; 82 / 48. Видимость: [16](16_линии.md). Подпись: [17](17_подпись_контура.md).

## 3. Код к таблице

**Сейчас.** Оси и номерация на полке «код» ([06](06_марки_спецификации.md), [12](12_ось.md)). TEXT-буквы на плане блока 1 сняты ([13](13_текст.md)). Стык со строкой — только если таблицу реально передали; на двух контрольных листах таблицы нет, на каждом коде note «таблица не найдена» ([19](19_код_к_таблице.md)). Ведомость не имитировали.

**Клик после шага.** «Ось А — …» / «помещение …» только если код стыкуется со строкой таблицы комплекта. Иначе note «таблица не найдена», не выдуманная расшифровка. Без выдачи заказчика не имитируем ([00_гост](00_гост_и_спецификация.md)).

**Не** подставлять справочник ГОСТ вместо схемы осей здания.

### Тесты

| Тест | Что проверяет |
|---|---|
| стык со строкой таблицы | клик «ось А — …» / номер из экспликации |
| таблицы нет | note, роль кода на месте |
| пустая графа | note, не «оси нет» |
| грунт / штамп | не стали кодом |
| без выдачи заказчика | расшифровка не выдумана |

### Анализ / ограничения

1. **Это спецификация комплекта, не ГОСТ.** ГОСТ говорит *как* подписать ось, не *какой набор осей у корпуса*.
2. **Не склеиваем пару на плане.** Буква и цифра на разных концах оси — два кода, пока нет схемы ([13](13_текст.md)).
3. **Номерация ≠ ось.** «5» на слое `0` по-прежнему не ось.

### Готово, когда

На геологии 60 INSERT-осей и на ТХ-1 25 TEXT-осей несут честный note «таблица не найдена»; имитации ведомости нет; 82 / 48. Стык код↔строка на фикстуре в тестах; на реальной таблице комплекта — когда её выдадут. Прогон двух листов: [19](19_код_к_таблице.md).

## 4. Именованный остаток

**Сейчас.** Трап, безымянный фахверк и пары мебели/сантехники — объекты ([07](07_классификация_значков.md), [18](18_именованный_остаток.md)). `CPE` без блока в ячейке легенды — note «нет стыка». Сварка — очередь ГОСТ, не этот шаг ([09](09_очередь_гост.md), [10](10_сварка.md)).

**Клик после шага.** Мебель/сантехника — «изделие», если стабильная пара имя+слой (как колонна). `CPE` — стык с легендой колонки или note «нет стыка». Не `*U`, не слой `SVARKA` целиком.

**Не** подписывать аббревиатуру скважины с потолка и не резать `SVARKA`.

### Тесты

| Тест | Что проверяет |
|---|---|
| пара имя+слой мебели/сантехники | `drawing_object`, не легенда |
| то же имя на чужом слое | unknown |
| `CPE` + стык с легендой колонки | подпись из строки |
| `CPE` без стыка | note «нет стыка», не выдуманная аббревиатура |
| `*U` на `0` | остаётся unknown |
| слой `SVARKA` целиком | не аннотация (`test_svarka_layer_is_not_annotation`) |
| confirmed | 82 / 48 |

### Анализ / ограничения

1. **Пара, не слой.** «Всё на Технология — оборудование» по-прежнему не пишем.
2. **Скважина — легенда колонки, не ГОСТ 21.302.** Аббревиатура софта без стыка не расшифровывается.
3. **Сварка не сюда.** Уникальные сигнатуры 2.312 — [09](09_очередь_гост.md) / карман зрительного ГОСТ.

### Готово, когда

Хотя бы один тип мебели/сантехники с парой имя+слой на полке объекта; `CPE` либо стыкуется, либо явно «нет стыка»; `*U` и `SVARKA` не сдвинулись; 82 / 48. Прогон двух листов: [18](18_именованный_остаток.md).

## 5. Легенда генплана

**Сейчас.** Словарь ПЗУ собран текстом ([02](02_проектная_легенда_и_конфликты.md)). На листе 2 легенда есть (23 строки); покрытие в XREF, на поле 4 штриха рамки без подписи. Конфликты рисунка заблокированы. Стык — только уникальный образец *этого* листа ([20](20_легенда_пзу.md), [17](17_подпись_контура.md)).

**Клик после шага.** Штриховка/линия на ПЗУ подписана строкой легенды **этого** листа, если образец совпал. Конфликты рисунка заблокированы и на другие листы не переносятся.

**Не** общестроительный ГОСТ генплана вместо «ворота с направляющими на этом объекте».

### Тесты

| Тест | Что проверяет |
|---|---|
| геометрия + строка легенды листа | подпись с этого листа |
| конфликт «один рисунок — несколько подписей» | блок, без переноса |
| нет геометрии шага 2 | легенда ПЗУ не применяется |
| грунт геологии | 82 не стали генпланом |
| чужой лист комплекта | конфликт/словарь ПЗУ не уехал |

### Анализ / ограничения

1. **После линий.** Без шага 2 подписывать нечего: на ПЗУ часто нет тех же INSERT.
2. **Конфликты уже известны.** Случаи в [02](02_проектная_легенда_и_конфликты.md) не разблокируем «чтобы хоть что-то подписалось».
3. **Не XREF.** Внешние ссылки комплекта по-прежнему дырявые; этот шаг их не чинит.

### Готово, когда

На контрольном ПЗУ (л.2) легенда листа есть, конфликты заблокированы, уникальный образец на поле не сел (XREF); геология **70 / 0**, не генплан. Стык «геометрия + строка этого листа» — в тестах. Прогон: [20](20_легенда_пзу.md).

## Когда уместен узкий зрительный ГОСТ

Не шаг этой очереди и не работа «сейчас».

Справочник ГОСТ уместен, когда клик уже знает *род* объекта (штамп, размер, кружок оси, сварной знак) **и** зоны листа размечены (шаг 1; линии поля — шаг 2, чтобы не сверять рамку таблицы с вилкой шва).

Узкий случай: вилка ГОСТ 2.312 на кропе **вставки на листе**, не определение блока в изоляции ([10](10_сварка.md): топ среза на определении — марка `ФС1` и штрихи, не таблица 2.312). Нет `gostCode` — роль не меняем. Слой `SVARKA` целиком не аннотация.

Не натягивать ГОСТ на трап, мебель, `CPE`, номерацию, безымянный `*U`.

## Как не смешать с очередью ГОСТ

[09](09_очередь_гост.md) — уникальные сигнатуры оформления внутри цели §5 п. 4: сварка 2.312, число размера, кружок оси. Эта очередь — **лист как документ** (зоны, линии, таблицы комплекта, именованный остаток, ПЗУ).

Не подменять: трап, мебель, `CPE`, номерация справочником 21.101 не подписываем.
