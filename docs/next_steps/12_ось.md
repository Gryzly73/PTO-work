# 12. Буква и цифра кружка оси (шаг 3 очереди ГОСТ)

План очереди: [09](09_очередь_гост.md). Размер: [11](11_размер.md). Марки: [06](06_марки_спецификации.md).

Это резюме **читалки граф оси**, не новый HTML-прогон десятки и не схема осей здания. Роли INSERT не менялись: confirmed / probable не трогали. Номерацию помещений не читаем.

## Кратко

Клик «ось Ж / 7» включается, если INSERT уже марка оси **и** буква/цифра доказаны. Пустой `Ось'` — заметка, не «оси нет». Теги `ДОП.МАРКЕР` / `Направление` именем оси не считаются.

Имя тега **не** значит «цифра vs буква»: на геологии `Ось=7` / `Ось'=Ж`, на покрытии `Ось=А` / `Ось'=2`. Классификатор смотрит на значение.

Сделано:

- модуль `dwg_symbols/axis_read.py`;
- поле `axis` у INSERT (letter / digit / label / source / note);
- карточка HTML: «Ось Ж / 7» сверху, сырые атрибуты ниже;
- `python -m dwg_symbols recount-axes`;
- юнит-тесты.

Docker десятки не делали: на геологии пары уже в sidecar. План блока 1 без блочных осей INSERT не выдумывали.

## Правила

| Вход | Что читаем |
|---|---|
| слой `OSI` или причина `AXIS_*` или тег `Ось` / `Ось'` | буква и цифра по **значению** |
| `номерация …` | не ось |
| `ДОП.МАРКЕР`, `Направление` | не имя оси |
| нет INSERT, только TEXT на плане | INSERT не создаём |

Fail-closed:

- пустой тег `Ось'` → «буква не прочитана», цифра из `Ось` остаётся;
- оба значения буквы или обе цифры → «буква и цифра не разошлись по полям», пару не угадываем;
- два разных TEXT в 8 мм → «несколько подписей рядом»;
- атрибут побеждает TEXT на уже заполненном слоте.

## Ограничения

1. **Это не схема осей комплекта.** «Ж / 7» — графы кружка. Что ось Ж проходит в этом корпусе — таблица заказчика, шаг 3 цели, не этот модуль.

2. **Тег `Ось` не всегда цифра.** На геологии цифра в `Ось`, буква в `Ось'`; на покрытии наоборот. Читаем значение.

3. **141 вставка на комплекте не разошлась.** В обоих полях буква или в обоих цифра. Пару не выдумываем.

4. **План блока 1 без блочных осей.** Буквы, скорее всего, TEXT. Конвейер INSERT их не видит. Пустой лист марок на ТХ-1 — не ошибка читалки.

5. **Соседний TEXT только в `review-sheet`.** Recount sidecar его не видит. Радиус 8 мм, слоты буква/цифра по отдельности.

6. **Не HTML-прогон десятки.** `review_10_stamp` не затирали. Графа «Ось» поедет при следующем `render-review-html` (live-чтение атрибутов).

7. **Номерация — другой словарь.** Блок `номерация 5` остаётся маркой помещения, без `axis`.

8. **Роли не менялись.** 82 / 48 на месте.
