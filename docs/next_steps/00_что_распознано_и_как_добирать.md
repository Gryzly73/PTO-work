# Что распознано и как добирать

Дата: 28.08.2026.  
Для заказчика. Одна схема: уже снято / ГОСТ / запрос клиенту / ещё анализ DWG / сознательно не распознаём.  
Шаги: [00_резюме_шагов.md](00_резюме_шагов.md). ГОСТ vs спецификация: [00_гост_и_спецификация.md](00_гост_и_спецификация.md). Покрытие ГОСТ: [00_гост_покрытие_и_проценты.md](00_гост_покрытие_и_проценты.md).

Знаменатель — вставки блоков (~8900 на 575 листах), не «каждый пиксель листа».

Распознано то, для чего в DWG уже были имя, слой, легенда листа или графа оформления. Дальше: ГОСТ — только штамп / размер / ось / типовая сварка; клиент — оси, помещения, ИГИ, внешние ссылки, ведомости; сами — текст и контуры на листе. Безымянные тысячи **не распознаются**, потому что в документе для них нет словаря, а выдумывать значок мы отказались.

---

## 1. Уже распознано (из файла, без клиента)

Клик знает **род**, а где хватило доказательства — ещё и **значение**.

| Что | Уровень | Опора |
|---|---|---|
| Грунты на разрезе, легенда **того же** листа | смысл, уверенно (~82 на контроле; на КР1 л.1 — 70) | совпадение блока с легендой листа |
| Те же грунты на других ИГР | смысл, **вероятно** (~876 по комплекту) | тот же рисунок блока, без ручной приёмки |
| Штамп | род + графы на контрольных 10/10 | слой / атрибуты + текст рамки |
| Колонна, трап, часть мебели | род «изделие» | пара **имя блока + слой** |
| Безымянный фахверк / стойки / фундамент | род «конструкция, не значок» (~1400) | анонимный блок + конструктивный слой |
| Размер / отметка как оформление | род; число у **отметок** (~475) | слой + атрибут |
| Кружок оси | род; буква и цифра у ~47% | слой `OSI` + графы |
| Номер помещения, «АБК» | род «код / подпись», не грунт | имя блока |
| Зоны листа (штамп / легенда / поле) | карта клика, узко на контроле | якоря текста |
| Штриховка на геологии | часть подписана образцом **этого** листа (~34) | уникальный штрих / HATCH легенды |

Это достигнутый каркас: грунт ≠ штамп ≠ колонна ≠ «не знаем».

## 2. Имеет смысл добрать через ГОСТ (оформление, не объект)

Справочник 21.101 / 2.312 и аналоги — только «как нарисовано».

| Имеет смысл | Зачем | Сейчас |
|---|---|---|
| Штамп: те же графы по **тексту** на всех 575 | шифр сейчас из атрибутов почти пустой | 10 листов уже так читаются |
| Размерная цепь как приём + число, если оно в файле | «3500», не только «это размер» | из блока ~0; текст снят на 2 планах |
| Кружок оси: буква / цифра | графика оси | ~половина комплекта |
| **Уникальные** сварные рисунки ↔ таблица 2.312 | тип шва | механизм есть, кодов 0: топ не 2.312 |

**Не через ГОСТ:** грунт, трап, помещение, бордюр, марки скважин, безымянный блок на слое `0`.

## 3. Имеет смысл запросить у клиента (словарь объекта)

Не альбом ГОСТ и не список ~3200 безымянных блоков.

| Запрос | Закроет | Без этого |
|---|---|---|
| Схема осей, экспликация помещений | «ось Ж — …», «номерация 5 — …» | навсегда заметка «таблица не найдена» |
| Том ИГИ / легенда колонки | марки скважин (~520) | «нет стыка», не скважина |
| Ведомость ТХ / КМ, марки дверей и окон | именованное оборудование | род есть, смысл изделия нет |
| Папка внешних ссылок (XREF) + легенда ПЗУ как в модели | покрытие генплана | легенда на листе, поле пустое |
| По желанию: полстраницы «что на слое `0` / `SVARKA`» | сверка спорных имён слоёв | **не** подпись ~3200 безымянных блоков |

**XREF** — чертёж подключает другой DWG как подложку. Глаз видит генплан целиком; в разбираемом листе на поле часто нет своих вставок, только ссылка. Нужна папка связанных файлов, не новый ГОСТ.

Источник запросов — комплектация проекта и авторы DWG, не 21.101.

## 4. Имеет смысл дальше разобрать чертёж самим

То, что уже лежит в DWG, но ещё узко или не снято.

| Анализ | Зачем |
|---|---|
| Текст осей и размерных цепей на остальных планах | как на двух планах блока 1: «6000», буквы без блока-кружка |
| Разбор штампа по тексту рамки на комплекте | шифр и название без пустых атрибутов |
| Контур и штриховка на поле, образец **этого** листа | стены / покрытия, где легенда уникальна |
| Соседний текст к безымянному блоку | иногда род («засечка», «выноска»), редко имя значка |
| Подтянуть внешние ссылки, когда папка будет | иначе генплан не из чего подписывать |
| Сверка сварки глазом по **уникальным** рисункам | ненулевой 2.312 только при совпадении с таблицей |

Это не нейросеть на весь лист и не перебор всех безымянных блоков.

---

## 5. Предполагается не быть распознанным — и почему

| Что | Почему не обещаем |
|---|---|
| **~3200 безымянных блоков** (часто слой `0`) | В файле нет имени, легенды и графы ГОСТ. Это обломки модели (взрыв блока, каркас, засечки). Назначить значок = выдумка. Клиент их тоже обычно не именует |
| Один рисунок — несколько подписей (конфликты генплана) | Автоматом нельзя выбрать «озеленение» против «ворот». Заблокировано намеренно |
| Тип шва, пока картинка ≠ таблица 2.312 | Похожие чёрточки ≠ стыковой шов |
| Смысл оси / помещения без ведомости | ГОСТ учит *как* подписать, не *что* значит «Ж» в этом корпусе |
| Покрытие генплана без внешних ссылок | Объекты не на том листе, который читаем |
| Фамилии ГИП; пустой «шифр» как «шифра нет» | Пустая графа ≠ факта «нет» |
| Весь лист одной нейросетью | Без полок штамп станет оборудованием, грунт — подписью |

Это не недоработка и не «клиент не прислал 3200 подписей». Это **граница доказательства**: нет стыка в файле и нет таблицы объекта — ответ остаётся «не знаем».
