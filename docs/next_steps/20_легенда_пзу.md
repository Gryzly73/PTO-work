## Правила

| Вход | Подпись |
|---|---|
| уникальный образец **этого** листа + геометрия шага 2 | строка легенды листа |
| один рисунок — несколько подписей ([02](02_проектная_легенда_и_конфликты.md)) | без подписи, без переноса |
| нет геометрии шага 2 / только легенда | легенда ПЗУ не применяется |
| словарь другого файла / ГОСТ генплана | не применяем |
| грунт-INSERT геологии | остаётся confirmed, не генплан |

## Ограничения

1. **XREF.** Покрытие, стрелки движения и ограждение лежат во внешней ссылке. Этот шаг её не чинит ([14](14_очередь_листа.md) §5.3). Без XREF подписывать на поле нечего — 0 подписей на `pzu-p2` это fail-closed, не «ворота из ГОСТ».
2. **Конфликты не разблокировали.** Чтобы хоть что-то подписалось, четыре случая из [02](02_проектная_легенда_и_конфликты.md) не открывали.
3. **Не ГОСТ.** «Проектируемое ограждение (периметровое)» — строка этого комплекта, не 21.204.
4. **Два листа, не десятка.** `review_10_codes` цел. 82 / 48 не трогали.
5. **Лист 1 ПЗУ** (`pzu-negative-p1`) по-прежнему без легенды — контроль был лист 2.
