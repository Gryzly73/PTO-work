## Кратко

Мебель и сантехника садятся на полку объекта только при **зафиксированной паре** имя блока + слой (как колонна и трап). Чужой слой — unknown. `CPE` / `PR_*` не становятся «скважиной»: если в ячейке легенды есть тот же блок — H4 confirmed; иначе note «нет стыка».

На ТХ-1 **+37** изделий (`FURNITURE_BLOCK_LAYER`). На геологии **76** геознаков с `GEOLOGY_NO_LEGEND_JOIN`; 70 confirmed грунтов на месте.

## Правила

| Вход | Роль | Подпись |
|---|---|---|
| имя из инвентаря **и** свой слой | `drawing_object` | изделие, не легенда |
| то же имя на чужом слое / слой `0` | unknown | нет |
| `CPE` в ячейке легенды (уникальный блок) | confirmed | строка легенды (H4) |
| `CPE` без блока в ячейке | `field_candidate` | note «нет стыка» |

| слой `SVARKA` целиком | unknown | не аннотация |

## Ограничения

1. **Не ведомость.** Клик говорит «изделие / раковина», не позицию из спецификации ТХ.
2. **Не слой целиком.** `АР_сантех` без своего имени не оборудование.
3. **CPE без стыка остаётся unknown.** Note честный; 76 геознаков геологии не confirmed.
4. **Два листа, не десятка и не 575.** `review_10_context` цел. 82 / 48 не трогали.
5. **§3 закрыт узко.** На кодах note «таблица не найдена», ведомость не имитировали ([19](19_код_к_таблице.md)).
