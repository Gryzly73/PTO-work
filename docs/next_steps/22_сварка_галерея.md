## Насколько обширна «вся полка» `gostCheck: worth`

В каталоге комплекта (575 страниц, 2694 типа / 8934 вставки) пометка `worth` стоит у **1424 типов / ~2882 вставок**. Это не «все unknown» и не один ГОСТ.

| Что в `worth` | Типов | Вставок | Нужна ли картинка для ГОСТ |
|---|---|---|---|
| Сварка `SVARKA` | **472** | **872** | да: форма знака 2.312 |
| Аннотация (размер, отметка, …) | ~643 | ~1297 | нет: число из атрибута / TEXT ([11](11_размер.md)) |
| Кружок оси `OSI` | 228 | 701 | нет: буква/цифра из тегов ([12](12_ось.md)) |
| Штамп / оформление листа | 81 | 148 | графы уже читаем ([08](08_чтение_штампа.md)); альбом 81 формы не сверяли |

Плюс полка `later` (не worth): арматура 112, уклон 2, штамп без атрибутов 1.

Итого: «вся полка worth» в ~3 раза шире сварки по типам (1424 vs 472), но для *зрительного* справочника сейчас уместна только сварка. Эта галерея — **122 типа** с четырёх листов, не 472.
