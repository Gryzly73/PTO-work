# 11. Число размера и отметки (шаг 2 очереди ГОСТ)

Дата: 27.08.2026.  
План очереди: [09](09_очередь_гост.md). Сварка: [10](10_сварка.md). Ось: [12](12_ось.md). Текст: [13](13_текст.md). Каталог: [07](07_классификация_значков.md).

Это резюме **читалки числа**, не новый HTML-прогон десятки. Роли INSERT не менялись: confirmed / probable не трогали. Слой `уклон` и `NADPISI` не читаем.

---

## Кратко

Клик «−2.950» / «3500» включается, если INSERT уже аннотация размера **и** число доказано. Пустой атрибут — заметка, не «размера нет». Теги видимости `В`/`Г` числом не считаются.

Сделано:

- модуль `dwg_symbols/dimension_read.py` (атрибут, затем уникальный соседний TEXT);
- поле `dimension` у INSERT (value / kind / source / note);
- карточка HTML: число сверху, сырые атрибуты ниже;
- `python -m dwg_symbols recount-dimensions` по sidecar без DWG;
- юнит-тесты.

Прогон Docker десятки не делали: отметки читаются из уже лежащих атрибутов; у размерной цепи числа в атрибутах почти нет.

## Правила

| Вход | kind | Откуда число |
|---|---|---|
| слой `OTMETKI`, тег `ОТМЕТКА` | `elevation` | атрибут, если похож на уровень (`-2.950`, `0.000`) |
| слой `RAZMER` | `linear` | теги `РАЗМЕР`/`ЗНАЧЕНИЕ` (на десятке их нет) → иначе соседний TEXT |
| блок `высоты …` | `height` | не имя блока; атрибут или TEXT |
| `NADPISI`, `уклон`, штамп, колонна, сварка | — | не читаем |

Fail-closed:

- пустой `ОТМЕТКА` → note «отметка не прочитана», не «отметки нет»;
- `В`/`Г`/`ВГ`/`ГГ`/`ПРИМ` — не число (на десятке 10 вставок только с ними);
- два разных числа в 8 мм → «несколько чисел рядом», значение не берём;
- атрибут побеждает TEXT, если оба есть.

---

## Ограничения

1. **Отметка и размерная цепь — разные полки.** `ОТМЕТКА` на `OTMETKI` читается. Цепь на `RAZMER` в атрибутах почти пустая: на десятке 50/60 без атрибутов, 10 — теги видимости динамического блока (`1 (6)`), не «3500».

2. **Число цепи часто не ATTRIB.** Оно в TEXT внутри блока или в сущности DIMENSION, которую конвейер INSERT не снимает. Соседний TEXT на листе подключается только в `review-sheet`, не в recount sidecar. Без нового прогона DWG «3500» на клике не появится.

3. **`высоты 1.1` — имя типа, не отметка.** Атрибутов нет (41 на десятке, 82 на комплекте). Высоту не выводим из названия блока.

4. **`NADPISI` / `_Open30` не размер.** Стрелка-выноска, не число.

5. **Соседний TEXT — узкий и спорный.** Радиус 8 мм, одно число на вставку. На размерной цепи вставки стоят часто; чужое «1200» не присваиваем (тест на два числа в одной точке). TEXT внутри определения блока сюда не входит.

6. **Не HTML-прогон десятки.** `review_10_stamp` / `review_10_context` не затирали. Карточка с графой «Отметка» поедет при следующем `render-review-html` / `review-sheet` (live-чтение атрибутов даже по старому sidecar).

7. **Роли не менялись.** Это не новый классификатор. 82 / 48 confirmed / probable на месте.

8. **Не смысл числа.** «−2.950» — прочитанная графа. Что это уровень чистого пола именно здесь — подпись `ПРИМ.`, не ГОСТ-справочник.

9. **`уклон` вне шага.** И приём оформления, и строка легенды ПЗУ.
