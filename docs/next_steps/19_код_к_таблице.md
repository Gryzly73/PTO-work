## Кратко

Клик «ось А — …» / «помещение …» садится **только** при уникальной строке таблицы, которую конвейеру реально передали. Живой прогон таблицу не ищет и не сочиняет: на каждом коде — note «таблица не найдена». Пустая графа оси по-прежнему «буква не прочитана», не «оси нет». Букву и цифру на плане не склеиваем. Грунт и штамп кодами не стали.

На геологии **60** INSERT-осей с note. На ТХ-1 блочных марок нет: **25** TEXT-осей (10 букв + 15 цифр) с тем же note; 25 линейных размеров без него.

## Правила

| Вход | Клик |
|---|---|
| уникальная строка таблицы (`kind` + код) | «ось А — …» / «помещение 5 — …» |
| таблицы нет (живой прогон) | note «таблица не найдена», роль кода на месте |
| таблица есть, этой строки нет | note «строка таблицы не найдена» |
| две строки с одним кодом | note «конфликт строк таблицы», без расшифровки |
| пустая графа оси | «буква не прочитана» (+ note таблицы), не «оси нет» |
| грунт / штамп / мебель / линейный TEXT | не код |

Строки в live-конвейер не подставляем. Стык проверяется юнит-тестом на фикстуре, не имитацией ведомости DWG.

---

## Ограничения

1. **Не ГОСТ.** Справочник 21.101 не говорит, какая ось у корпуса. Расшифровка — спецификация комплекта ([00_гост](00_гост_и_спецификация.md)).
2. **Не склейка пары.** Буква и цифра на разных концах оси — два кода ([13](13_текст.md)).
3. **Номерация ≠ ось.** На этих двух листах блока «номерация …» нет; механизм есть в тесте.
4. **Два листа, не десятка.** `review_10_named` цел. 82 / 48 не трогали.
5. **Выдача заказчика.** Пока нет схемы осей / экспликации, клик честно «таблица не найдена».
