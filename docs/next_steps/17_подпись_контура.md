## Кратко

Хеш большого контура больше не единственный стык. Подпись садится, если на *этом* листе уникален простой штрих ячейки легенды, нативный HATCH (`pattern|scale|color`) или прежний векторный хеш. Две строки с одним образцом — без подписи.

Нативный HATCH снимаем отдельно, в SVG листа по-прежнему `HatchPolicy.IGNORE`. Бюджет поля 160, сначала подписанные, затем hatch / line / closed — открытая линия не вытесняется 80 замкнутыми.

На геологии **34** штриховки подписаны строкой этого листа. На ТХ-1 подписей 0: уникального образца нет. Словарь ПЗУ не применяли.

## Правила

| Вход | Kind | Подпись |
|---|---|---|
| LINE/POLYLINE ≥ 8 мм, центр в поле | `line` / `closed` | уникальный простой штрих ячейки или `legend-vector-v1` |
| нативный HATCH (не Recorder) | `hatch` | уникальный `hatch-pattern-v1:PATTERN\|scale\|color` |
| две строки с одним образцом | то же | без подписи |
| цвет + толщина без геометрии | — | не стык |
| легенда ПЗУ / другого файла | — | не применяем |

INSERT не создаём. `HatchPolicy.IGNORE` на картинке листа не меняли.

## Ограничения

1. **Уникальный образец ≠ грунт.** На геологии села отметка УГВ, не `Fill`. Общие pattern грунтов заблокированы — это fail-closed, не словарь ПЗУ.

2. **Бюджет 160.** Hatch и line раньше closed. На ТХ-1 в окно попали сварка и окна; замкнутые стены — нет. Слой `SVARKA` целиком не классифицировали (это [09](09_очередь_гост.md)).

3. **Взорванный штрих легенды.** Если в ячейке больше 8 неколлинеарных отрезков, простой штрих не строится. Остаётся полный хеш или HATCH.

4. **Не легенда ПЗУ.** Лист без уникальной строки остаётся без подписи (ТХ-1, тест ПЗУ).

5. **Два листа, не десятка.** `review_10_stamp` / `context` / `zones` / `lines` целы. 82 / 48 не трогали.

6. **`drawing_field` не перерезали.**
