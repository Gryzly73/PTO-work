## Кратко

Клик «стыковой / угловой / …» включается **только** если сигнатура есть в `gost_welds.json` **и** заполнен `gostCode`.

Сделано:

- таблица и классификатор `WELD_GOST_SIGNATURE` → `drawing_annotation`;
- карточка HTML: графы «ГОСТ 2.312» / «Тип шва»;
- юнит-тесты (совпадение, сосед, пустой код, чужой слой, штамп/колонна/трап, полка каталога, прод-таблица без кодов);
- SVG четырёх **определений блоков** с покрытия КР1, покрытия блока 8 и колонн КР1.

Сверка: топ среза — **не знаки таблицы ГОСТ 2.312**. Коды не проставляли. Кроп **вставки на трёх листах** — то же: [21](21_сварка_вставка.md), 156 / 121, кодов нет.

Fail-closed классификатора:

- слой не `SVARKA` / `Сварка` → нет;
- сигнатуры нет в таблице → нет;
- есть строка, нет кода → нет;
- соседний `*U` на том же слое без строки → unknown.

Роль совпавшего (когда код появится) — оформление (`drawing_annotation`). Overlay без новой буквы: **A**.

## Ограничения

1. **Слой `SVARKA` — не очередь знаков 2.312.** На нём смешаны: (а) условное *изображение шва на стыке* (штрихи, кресты); (б) марки типовых элементов (`ФС1`); (в) возможно, настоящие обозначения из таблицы 2.312 — их в этом срезе нет. Резать слой целиком по-прежнему нельзя.

2. **Топ по числу вставок — плохая выборка для 2.312.** Самые частые блоки на покрытии и колоннах оказались геометрией шва и маркой «ФС1», не вилкой со вспомогательным знаком (треугольник / V / окружность контура). Частота не доказывает тип шва.

3. **ГОСТ 2.312 различает изображение и обозначение.** Кресты вдоль стыка и параллельные штрихи могут быть *как нарисован шов на виде*. Тип «стыковой / угловой / тавровый» даёт *обозначение* (полка-выноска и знак на ней). По пяти линиям или крестам тип не читается — оба вида швов так рисуют.

4. **`gostCode` без однозначной формы не ставим.** Не угадываем «угловой», потому что блок на слое сварки. Пустая строка в таблице — документ среза, не совпадение.

5. **Срез ≠ полка.** 4 типа / 72 вставки из 472 / 872. Остальные 468 не смотрели. Среди них как раз могут быть вилки 2.312; этот шаг их не нашёл и не исключил.

6. **Имя блока врёт.** `*U129` в одном файле — `*U346` / `*U38` в другом при той же сигнатуре. `ФС1_Есипово…` — копипаст с другого объекта, не код 2.312. Классификатор ключует `signature`.

7. **Слой INSERT ≠ слой содержимого.** У `ФС1` вставка на `SVARKA`, линии и текст внутри — `METALL`. Слой вставки не говорит, что это знак оформления.

8. **Кроп определения ≠ кроп на листе.** SVG из таблицы блоков: без соседей, без поворота вставки, без масштаба листа. Этого хватило, чтобы *отклонить* срез топа. Кроп вставки на трёх листах ([21](21_сварка_вставка.md)) полку 2.312 не добавил: соседи — размеры и контур, не треугольник / V / окружность.

9. **Нет HTML-прогона 3–5 листов и recount 575.** Контрольная десятка ТХ/АР для сварки слабая; `review_10_stamp` / `review_10_context` не трогали. 82 / 48 не пересчитывали — менять было нечего.

10. **Не закрывает клик по изделию.** Даже будущий код 2.312 — тип шва как графический приём, не позиция ведомости КМ и не «этот стык балки такой-то».

11. **Не OCR и не альбом ГОСТ в рантайме.** Таблица у нас, короткая. Нет кода — нет подписи в карточке.
