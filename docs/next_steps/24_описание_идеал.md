## Ограничения

1. **Это рендер из sidecar, не OCR.** Четыре разреза садятся по римской линии `XII-XII`; «Разрез по оси Д» без native TEXT не восстанавливается — два XIII с одним заголовком.
2. **Легенда дословно.** `label` sidecar, без ГОСТ-подстановки «ИГЭ-N». Нет `круг6` — нет ⑥ на XII.
3. **Роли INSERT не трогаем.** Confirmed / `legend_exemplar` / `CPE` как в [23](23_карточка_геология_кр1.md).
4. **Слои — INSERT в bbox, не штриховка.** Список на XII расходится с глазом ИДЕАЛ_08 (там ③⑥, здесь ⑨⑫), потому что в колонке нет `круг3`/`круг6`.
5. **Схема скважин** без `кругN` в своём bbox — слоты **ИЗ ЧЕГО** / **КАК** «не прочитано»; номера «Скв. 353» — шаг 5, вне очереди.
6. **Не затираем** каталоги `review_10_*`. Контроль КР1 — `review_ideal_kr1`; три ИГР — `review_ideal_igr`.
7. **Не VLM и не Docker 575.** Один лист, не десятка. ИГР без локальной легенды: подпись ⑦ с каталога КР1 как `probable`, не confirmed.
