# 8. Чтение основной надписи (графы ГОСТ 21.101)

Источник: прогон 10 листов `local_runs/review_10_stamp` (каталог `review_10_context` не затирали) и пересчёт атрибутов sidecar `local_runs/project_application/title_block_attr_recount.json` (575 страниц, без новой конвертации DWG).  
Дата: 27.08.2026.

Цель клика: не «это оформление», а **стадия / лист / листов / шифр** (название листа — если геометрия его дала). ГОСТ 21.101 задаёт *где* графа; значения — из DWG. Фамилии ГИП, альбом форм, OCR/VLM и сварка — вне скоупа.

Общий HTML: [review_10_stamp/index.html](../../local_runs/review_10_stamp/index.html). Overlay: серый пунктир зоны штампа, без новой буквы; в легенде SVG строка «зона основной надписи». Поле чертежа в JSON (`drawing_field`), на лист не заливаем.

Команды:

```
python -m dwg_symbols recount-title-block local_runs/project_application \
  --out local_runs/project_application/title_block_attr_recount.json
```

## Кратко

Штамп уже умели *находить* (шаг 03: INSERT на `FORMAT` / по атрибутам). Этот шаг *читает* графы.

- Слой 1 — атрибуты INSERT: `ЛИСТ` → sheet, `ЛИСТОВ` → sheetsTotal, `СТАДИЯ` → stage. Непустой `ШИФР` — только если проходит `_looks_like_code`. Пустой `ШИФР` **не** значит «шифра нет».
- Слой 2 — `stamp.read` по TEXT листа. Шифр и наименование — отсюда. Если атрибут листа/стадии заполнен и расходится с геометрией — в `note` конфликт, **атрибут побеждает**.
- Нет INSERT, но якоря «Стадия/Лист» в текстах есть (взорванный штамп, фундаменты КР1) — `titleBlock` без `instanceId`, зона по якорям, INSERT не выдумываем.
- Блок «подпись» (`SIGNATURE_BLOCK`) — не основная надпись.

На 10 листах шифр прочитан у всех десяти (`28-ХСА-1/25-ТХ` / `КР1` / `АР1` / `АР2` / `ПЗУ`). Confirmed / probable не сдвинулись (**82 / 48**). Unknown, объекты, марки — как в `review_10_context`.
