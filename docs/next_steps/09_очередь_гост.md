## Рамка (на все три шага)

- Ключ типа — `signature` определения блока (`blockdef-v1:` + хэш), не имя слоя и не каждая вставка.
- Fail-closed: нет доказательства формы → роль не меняем.
- Конвейер ролей не ломаем. Слой `SVARKA` целиком в аннотацию **не** сбрасываем (`test_svarka_layer_is_not_annotation`).
- Прогоны — новые каталоги (`review_weld_*`, `review_10_dims`, …). `review_10_stamp` / `review_10_context` не затираем.
- Не делаем: OCR/VLM на лист; перебор ~3227 безымянных `*U` на слое `0`; «всё unknown — по ГОСТ»; привязка шва к ведомости КМ; фамилии ГИП; сверка 81 формы штампа.

Контроль регрессии на старой десятке (ТХ/АР/КР/геология/ПЗУ): confirmed / probable **82 / 48**.

Десятка ТХ/АР для **сварки слабая**: на ней `SVARKA` почти нет. Листы брать из каталога: покрытие КР1, колонны, АБК, узлы КМ.

## 1. Сварка — ГОСТ 2.312

**Сейчас.** Каталог: 472 типа / 872 вставки, роль конвейера `unknown`, `gostCheck: worth`. Слои `SVARKA` (858) и `Сварка` (14). 469 типов безымянные. Именованный крупный: `ФС1_Есипово 3_стр3` — 30 экз. на покрытии КР1.

**Клик после шага.** Тип шва по таблице 2.312. Не позиция в ведомости КМ.

**Не** подписывать все 872 копии и не резать слой целиком.

### 1.1. Срез, не вся полка

Старт — узкий набор по числу листов / повторов, не 472 строки:

| Ориентир из [07](07_классификация_значков.md) | Экз. | Где |
|---|---|---|
| `ФС1_Есипово 3_стр3` | 30 | покрытие КР1, лл. 1–2 |
| `*U129` | 18 | покрытие блоков 8–10, листы ~43–60 |
| `*U140` / `*U152` | по 12 | колонны КР1 и АБК блока 10 |

Остальные 464 типа — только если форма на топе сошлась. **Топ среза после кропов не сошёлся** ([10](10_сварка.md)): марка `ФС1` и штрихи/кресты шва, не вилка таблицы 2.312. Кроп вставки на трёх листах тоже не сошёлся ([21](21_сварка_вставка.md)): 121 тип, 0 кодов. Остальные вставки на `SVARKA` без строки с кодом остаются unknown.

### 1.2. Таблица соответствий у нас

Не «альбом ГОСТ в рантайме». Файл [`dwg_symbols/gost_welds.json`](../../dwg_symbols/gost_welds.json): `signature` → код 2.312 + короткая подпись. Механизм и тесты — [10](10_сварка.md).

Нет `gostCode` — тип не трогаем (сейчас так у всех четырёх строк среза после сверки кропов). Совпала — причина `WELD_GOST_SIGNATURE`. Роль для совпавших — `drawing_annotation` (знак оформления), не `drawing_object` и не легенда.

Сверку кропа с таблицей швов делает человек (или отдельный проход по уникальным SVG), не классификатор слоя.

### 1.3. Контракт, тесты, прогон

Sidecar: у совпавшего INSERT — роль/причина; подпись шва в карточке HTML. Overlay без новой буквы или одна `W`, как F/O/A/M.

Юнит-тесты:

- сигнатура из таблицы → annotation + причина;
- соседний `*U` на `SVARKA` без строки → unknown;
- колонна / трап / штамп не двигаются;
- слой `SVARKA` целиком по-прежнему не аннотация;
- срез без `gostCode` остаётся unknown;
- прод-таблица после сверки кропов без включённых кодов.

Кропы определений среза: [review_weld_crops](../../local_runs/review_weld_crops/). Кропы вставок на трёх листах: [review_weld_inserts](../../local_runs/review_weld_inserts/). HTML 3–5 листов и recount 575 не делали: коды не появились. На контрольной десятке 82 / 48.

Документ сверки среза — [10](10_сварка.md); вставок на листе — [21](21_сварка_вставка.md); галерея кропов — [22](22_сварка_галерея.md).

## 3. Кружок оси — графика, не код здания

**Сейчас.** Читалка есть: [12](12_ось.md). 228 типов, слой `OSI` уже `specification_mark`. Буква и цифра — по **значению** тегов, не по имени `Ось` vs `Ось'` (геология `7`/`Ж`, покрытие `А`/`2`). На десятке 60/60 оба поля (геология). На 575 страницах: 703 кандидата, **331** оба поля, 141 не разошлись, 77 пусто. Маркеры и номерация не имя оси.

**Клик.** «Ось Ж / 7», если слоты разошлись. Пустой `Ось'` — заметка, не «оси нет». План без INSERT (ТХ-1) — INSERT не выдумываем; буквы там TEXT.

ГОСТ даёт «это координатная ось»; «ось Ж проходит здесь в этом корпусе» — схема осей комплекта, не этот шаг ([00_гост](00_гост_и_спецификация.md), цель §5 п. 3).

Не искать экспликацию и не подписывать номерацию помещений. Docker десятки не делали. 82 / 48.
